//! Path cost computation. //! //! **Improvement 3-A: Scarcity-Aware Routing** //! Four Vertical Concerns (reinforced by v2 fixes)

Data plane — p4_driver feeds raw telemetry upward and issues priority hardware interrupts (3-B). The DMA ring is now a lock-free ArrayQueue (FIX-F), eliminating the spinlock priority inversion that could deadlock the FPGA interrupt path.

AI layer — digital_twin maintains pure-EWMA-Welford per-link state (FIX-A — m2 now decays, never diverges). The fixed-point kernel path also enforces an epsilon floor so the Z-score denominator is always non-zero (FIX-B). Concurrent updates from P4 telemetry bursts are now safe (FIX-C — DashMap atomic entry mutation). If the calibration thread panics, the Mutex recovers transparently (FIX-D).

Routing layer — routing::engine uses the scarcity-aware cost formula (3-A). All Kani harnesses are annotated with #[kani::unwind(N)] (FIX-I) so the model checker can formally prove bounded termination and therefore that the 1 ms tick cannot be violated by mathematical loops.

Kernel — qib-muk provides fixed-point scheduling (1-A), typed quantum capabilities with Epoch/Generation IDs (FIX-H — revoked caps are dead on the very next tick), zero-copy ring IPC (1-C), TEE attestation enforcement with temporal leases (FIX-G — no permanently-trusted-but- compromised node), and a safe-bypass panic handler (5-A). The isqrt_u64 loop is unrolled to exactly 6 iterations (FIX-E), converting a data-dependent latency source into a constant-time operation.
